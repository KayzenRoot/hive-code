# Project Overview

## Product
Hive Code is a governed AI-native coding and software-construction platform derived from the imported Goose codebase and intended to evolve under its own architecture, identity and product requirements.

## Current baseline
- Repository: `KayzenRoot/hive-code`
- Imported baseline: Goose codebase, preserved through `goose-main` and merged into `main` by bootstrap commit `e25ddce2655f8f5eaf5506df7478f8e336a18eaa`.
- Upstream GitHub workflow files were intentionally excluded during bootstrap because the available GitHub Actions token could not publish upstream workflow files.
- No Hive Code product rebranding or feature divergence is claimed yet.

## Construction model
GEF V1 governance is mandatory by default. Brownfield adoption is preservation-first and progressive. Existing working architecture is not rewritten merely to satisfy process conventions.

## Version objective
Establish a verifiable, governed Hive Code baseline before product changes begin.
