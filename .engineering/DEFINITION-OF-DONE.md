# Definition of Done

An increment is DONE only when all applicable conditions are evidenced:

1. Work Order scope and acceptance criteria satisfied.
2. No known HIGH/CRITICAL defect remains.
3. Required tests/checks pass at the assigned risk tier.
4. Architecture/security/data/contracts remain valid or are updated with evidence.
5. Documentation does not overclaim implementation.
6. Evidence Bundle binds exact base/head SHAs.
7. PR is auditable and review result is `APPROVED`.
8. Checkpoint Delta is reviewed before canonical promotion.
9. Merge completes without bypassing unresolved required gates.
10. Deployment/validation evidence exists when the increment changes a deployable product surface.

## Version completion
Hive Code V1 is complete only when its version-level scope and all applicable production, security, testing, deployment and operational requirements are objectively satisfied.
