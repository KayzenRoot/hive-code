- Official name: **Hive Code**
- Repository: `KayzenRoot/hive-code`

- Upstream technical origin: Goose (`aaif-goose/goose`), preserved as provenance where legally/technically required

## Brand concept

Hive Code represents coordinated software construction: agents, tools, context and evidence operating as one governed engineering system. The product identity must be distinct from Goose and must not imply endorsement by AAIF, Block, Goose maintainers or previous contributors.

## Naming rules

### User-facing
Use `Hive Code` for desktop app name, documentation product name, headings, About surfaces, distribution descriptions and marketing copy.

### Short form
`Hive` may be used only where context clearly refers to Hive Code and cannot be confused with other Hive-family projects.

### CLI
Target command: `hive-code`.

The inherited `goose` CLI command remains a compatibility surface until a governed technical migration proves that installers, scripts, integrations, ACP/MCP tooling, updater behavior and user data paths can be migrated without regressions. Do not rename it blindly.

## Provenance rule

Hive Code is a derivative project built from the imported Goose codebase. Required Apache 2.0 license/copyright/NOTICE obligations and applicable historical attribution are preserved. Provenance is not current project membership and does not make upstream authors Hive Code maintainers or contributors to new Hive Code work.

## Trademark separation

Do not present Goose, AAIF or Block names/logos as Hive Code branding. References to Goose should be limited to provenance, compatibility, migration documentation, preserved historical content or factual technical context.

## STOP

Brand identity changes that affect executable/package identifiers, persistent data paths, distribution coordinates or compatibility surfaces require an explicit Work Order and evidence.
